# Feature preservation inventory

All rows are **retained initially**. “Source only” means entry points were inspected, not that the behavior works. No hardware, runtime, or packaged-build verification has been performed for this baseline. External consumers beyond those visible in the repository remain unknown. Use [testing.md](testing.md) for the matching verification scenarios.

Paths below are repository-relative. Shared authoritative machine state belongs to `index.js`; renderer snapshots/settings belong to `app/js/websocket.js` unless a row says otherwise.
