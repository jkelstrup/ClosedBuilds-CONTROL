# Feature preservation inventory

Rows are **retained initially** except the inherited application updater, explicitly disabled by maintainer request because CBC diverges from the abandoned baseline. “Source only” means entry points were inspected, not that the behavior works. Later narrow runtime/package evidence is noted per row; no hardware behavior has been verified. External consumers beyond those visible in the repository remain unknown. Use [testing.md](testing.md) for exact evidence and remaining scenarios.

Paths below are repository-relative. Shared authoritative machine state belongs to `index.js`; renderer snapshots/settings belong to `app/js/websocket.js` unless a row says otherwise.
